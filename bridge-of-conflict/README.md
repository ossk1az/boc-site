# Bridge of Conflict — сайт-лендинг

Статический сайт: HTML + CSS + JavaScript, без сборки и бэкенда. Достаточно загрузить папку на GitHub Pages или любой хостинг.

| Файл | Что внутри |
|---|---|
| `index.html` | Каркас страницы, SEO-теги (title, description, Open Graph), подключение шрифтов |
| `js/content.js` | **Все тексты и ссылки сайта** — правьте здесь |
| `js/main.js` | Логика: отрисовка блоков, таймер Битвы за мост, подсветка праздника, меню |
| `css/style.css` | Оформление; цвета собраны в `:root` в начале файла |
| `img/favicon.svg` | Значок-заглушка |
| `img/og.jpg` | Картинка-заглушка для соцсетей (1200×630) |

## Что заполнить

1. **Ссылки** — блок `links` в начале `js/content.js`: Discord, клиент, адрес сервера.
2. **Пометки `<ЗАПОЛНИТЬ: ...>`** — на сайте подсвечены жёлтым (доп. правила, даты Купалы и Праздника урожая).
3. **Картинки** — положите в `img/` файлы с этими именами, заглушки исчезнут сами:
   - `hero.jpg` — скриншот моста на закате (широкий, ~1920×1080)
   - `order.jpg` — замок Британии (16:9)
   - `chaos.jpg` — крепость Хаоса на острове (16:9)
   - `outcasts.jpg` — канализация Британии (16:9)
   - `bridge-battle.jpg` — Битва за мост: жаровни и Ancient Wyrm
   - `steed.jpg` — Mondain's Steed (4:3)
   - `og.jpg` — картинка для соцсетей, 1200×630
4. **Open Graph** — после публикации замените в `index.html` `og:image` на полный адрес (`https://ваш-сайт/img/og.jpg`).

Время Битвы за мост и часовой пояс — блок `battle` в `js/content.js`.
